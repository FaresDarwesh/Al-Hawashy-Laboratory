# معمل الحوشي للتحاليل الطبية — موقع إلكتروني متكامل

> **جديد ولازم تبدأ منه:** لو جاي تنشر التحديث على Vercel، افتح ملف **`اقراني-الأول-7-خطوات.md`** الأول — فيه سبب إن التعديلات مكانتش بتظهر عندك، والـ 7 خطوات (أهمها **Push origin** في GitHub Desktop).

موقع ثابت (HTML/CSS/JS خالص — بدون أي مكتبة خارجية) فيه: حجز أونلاين، سحب منزلي، رفع روشتة، سجل طبي للمريض، لوحة تحكم للمدير، بوابة للأطباء، واتصال اختياري بقاعدة بيانات سحابية (Supabase).

## المميزات

- **الرئيسية:** هيرو متحرك (جزيئات)، خدمات، بحث فوري في التحاليل والأسعار، باقات، خطوات الحجز، فروع، فريق طبي، آراء، أسئلة شائعة.
- **الحجز (4 خطوات):** نوع السحب (منزلي/في المعمل) → التحاليل والباقات → البيانات (واتساب + الطبيب المعاين + العنوان والمنطقة) → الدفع (كاش وقت الكشف أو انستا باي مع رفع الإيصال). ملخص فوري بالرسوم ورسوم السحب حسب المنطقة.
- **رفع الروشتة:** رفع صورة/نص → تحليل ذكي يطابق التحاليل ويحسب الإجمالي فوراً → إشعار للأدمن والأطباء → الرد بالتسعيرة.
- **تتبع الحجز:** بكود الحجز + رقم الموبايل، مع تايم لاين الحالة ورفع إيصال الدفع.
- **الملف الطبي للمريض:** دخول بآخر ٦ أرقام من الموبايل — التحاليل، النتائج، الروشتات، الفواتير، بطاقة المريض (QR).
- **لوحة المدير (16 شاشة):** نظرة عامة + رسوم بيانية + خريطة أوقات الذروة، الحجوزات، الروشتات، المرضى، المالية، التحاليل، الباقات، الفروع، الدكاترة والصلاحيات، المناطق ورسوم السحب، العروض، المحتوى، مركز الرسائل (واتساب)، ملصق QR للطباعة، الإعدادات، السجلات.
- **بوابة الطبيب (9 شاشات):** حجوزاته، تسعير الكشف المنزلي لكل منطقة، استلام حجز من المعمل، الروشتات، المرضى، حساباته.
- **QR من الصفر:** مولّد QR كود مكتوب بالكامل داخل المشروع (بدون مكتبات) — بيظهر في إيصال الحجز، بطاقة المريض، صفحة التتبع، وشاشات المدير والطبيب، وكمان ملصق A4 للطباعة.
- **وضع نهاري جميل + وضع ليلي** — زر تبديل في الهيدر، والاختيار محفوظ في المتصفح.
- تصميم زجاجي حديث، شريط إعلاني متحرك، شريط تقدم القراءة، حركات وكروت تفاعلية، وتوافق كامل مع الموبايل والتابلت واللاب.
- **PWA:** يشتغل offline ويتثبت كأبلكيشن على الموبايل (manifest + service worker).
- **مزامنة سحابية اختيارية مع Supabase:** كل الحجوزات والبيانات بتظهر على كل الأجهزة فوراً — بتفعّلها من إعدادات الأدمن.

## بيانات الدخول

| المستخدم | اسم المستخدم | كلمة المرور |
|---|---|---|
| المدير العام | `admin` | `Mo@010` |
| طبيب | `heba` | `123456` |
| طبيب | `kareem` | `123456` |
| المريض | رقم الموبايل | آخر ٦ أرقام من الموبايل |

الفروع: **فرع برج النور الحمص** و **فرع منشأه الاخوة**.
المناطق: شنفاس، البهو فريك، السبخا، ديرب، بقطارس، برج النور الحمص، المنشيه.

## التشغيل محلياً

الموقع ثابت 100% — أي سيرفر بسيط يكفي:

```bash
cd elhoshy-lab
python3 -m http.server 3000
# افتح http://localhost:3000
```

أو على ويندوز: ثبّت **Live Server** في VS Code واضغط كليك يمين على `index.html` → Open with Live Server.

## النشر والربط السحابي

اتبع **`دليل-النشر-خطوة-بخطوة.md`** — بيشرح بالترتيب: مزوّد قاعدة البيانات ← GitHub Desktop ← Vercel ← تفعيل المزامنة.

1. أنشئ مشروع على **supabase.com**، شغّل `supabase/schema.sql` في SQL Editor، واعمل bucket عام اسمه `lab-files`.
2. من Settings ▸ API خد **Project URL** و **anon public key**.
3. ارفع المشروع على GitHub بـ GitHub Desktop.
2. استورد الريبو في Vercel واضغط Deploy.
3. من `admin.html` → الإعدادات → الربط السحابي → اختار المزوّد والصق البيانات → حفظ واختبار الاتصال.

📄 **`شرح-الكود-بالتفصيل.md`** — توثيق كامل لكل ملف ودالة وجدول وبروتوكول المزامنة.

بعد كده أي `Commit` + `Push` من GitHub Desktop بينشر أوتوماتيك على Vercel.

## ملاحظات

- كل البيانات بتتخزن في المتصفح (localStorage) وبيتزامن مع السحاب لو فعّلته.
- الملفات الكبيرة (صور الروشتات أكبر من 350KB) بتترفع تلقائياً على Supabase Storage بدل ما تتخزن كـ base64.
- من لوحة المدير → الإعدادات → تصدير نسخة كاملة (JSON) لعمل نسخة احتياطية.
