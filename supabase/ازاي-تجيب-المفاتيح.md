# أولًا: إنشاء مجلد الصور (Storage Bucket)

> المجلد ده بيستقبل: صور الروشتات، إيصالات الدفع، صور الدكاترة، ملفات المرضى.

1. من **القائمة الجانبية على الشمال** في لوحة Supabase، اضغط أيقونة **Storage** (شكل علبة/أرشيف).
2. فوق على اليمين اضغط الزر **New bucket**.
3. هيظهر مربع املاه بالظبط كده:
   - **Name of bucket:** `lab-files` ← **بالإنجليزي الصغير وبالظبط من غير مسافات**
   - **Public bucket:** اضغط المفتاح علشان يبقى **مفعّل** ✅ (لازم — لو مش مفعّل الصور مش هتظهر للمريض)
   - **File size limit:** سيبه زي ما هو (50 MB)
   - **Allowed MIME types:** سيبه فاضي (يعني كل الأنواع)
4. اضغط **Create** (زر أخضر/أزرق تحت).
5. ✅ **التأكيد:** هتلاقي في القائمة اسم **`lab-files`** وتحته كلمة **Public**.

> لو نسيت تفعل Public: اضغط على النقاط الثلاث `⋯` جنب اسم المجلد → **Edit bucket** → فعّل Public → Save.

# ثانيًا: Project URL (رابط المشروع)

1. من القائمة الجانبية تحت، اضغط أيقونة **Project Settings** (الترس ⚙).
   - أو من الشريط الفوقاني: اضغط على **اسم المشروع** → **Project Settings**.
2. من قائمة الإعدادات اللي ظاهرة (تبويبات فوق)، اضغط **Data API** — وفي الواجهة القديمة اسمها **API**.
3. أول كارت فوق اسمه **Project URL** — هتلاقي مربع رمادي فيه الرابط، وجمبه أيقونة نسخ 📋. اضغطها.

### 📌 شكل النتيجة الحقيقي:
```
https://qwrtyxmnbvcxzasdfghj.supabase.co
```

الرابط بيتكون من ٣ أجزاء:
| الجزء | القيمة | ملاحظة |
|---|---|---|
| البروتوكول | `https://` | لازم `https` مش `http` |
| كود المشروع | `qwrtyxmnbvcxzasdfghj` | 20 حرف إنجليزي صغير — بيتولد تلقائي وبيختلف من مشروع للتاني |
| النطاق | `.supabase.co` | ثابت |

أمثلة تانية لروابط صحيحة:
```
https://abcdefghijklmnopqrst.supabase.co
https://elhoshy-lab-2026.supabase.co
```

❌ **أخطاء شائعة متعملهاش:**
- تنسخ الرابط وفي آخره `/` → امسحها.
- تكتب `http://` بدل `https://`.
- تنسخ رابط الـ Dashboard (`https://supabase.com/dashboard/project/...`) → ده **مش** المطلوب.

## ⛔ المفتاح اللي ممنوع تنسخه

| المفتاح | شكله | استخدمه؟ |
|---|---|---|
| Publishable key | `sb_publishable_...` | ✅ **آه — ده المطلوب** |
| anon (قديم) | `eyJhbGciOi...` | ✅ **آه — بيشتغل برضه** |
| **Secret key** | `sb_secret_...` | ❌ **أبداً — بيعدي على الحماية وبيكشف كل البيانات** |
| **service_role** (قديم) | `eyJhbGciOi...` وفيه `"role":"service_role"` | ❌ **أبداً** |

> الخلاصة: **الكلمة اللي في اسم المفتاح لازم تكون publishable أو anon**. لو لقيت كلمة secret أو service_role → متنسخهوش.

# رابعًا: النتيجة النهائية اللي هتحطها

بعد الخطوات دي، المفروض تكون معاك الحاجتين دول زي كده بالظبط:

```
Project URL          : https://qwrtyxmnbvcxzasdfghj.supabase.co
anon / publishable   : sb_publishable_9Xk2LmQ7vTzR4nB8cFdGhJ_2vQ8rTnK6wYzLpXcQaZs
اسم مجلد الصور       : lab-files
```

**احفظهم في مفكرة أو في رسالة لنفسك على واتساب** — هتحتاجهم تاني لما تفتح لوحة المدير من جهاز تاني.

# خامسًا: إزاي تحطهم في الموقع

1. افتح الموقع على Vercel: `رابط-موقعك/admin.html`
2. سجّل الدخول: `admin` / `Mo@010`
3. من القائمة الجانبية: **الإعدادات**
4. انزل لآخر الصفحة — كارت **الربط السحابي**
5. املأ:
   - **Project URL** ← الصق الرابط
   - **anon public key** ← الصق المفتاح
   - **مجلد الملفات (Bucket)** ← اكتب `lab-files`
   - **المزامنة** ← مفعّلة
6. اضغط **حفظ واختبار الاتصال**

### ✅ شكل النجاح:
رسالة خضراء: **«نجح الاتصال — السحاب جاهز وكل الأجهزة هتتزامن»**
+ شارة صغيرة تحت على الشمال مكتوب فيها **«متصل بالسحاب»** بنقطة خضرا.

### ❌ لو ظهرت مشكلة:

| الرسالة | السبب | الحل |
|---|---|---|
| **Invalid JWT** | نسخت Secret key أو service_role | ارجع وانسخ **publishable / anon** |
| **تعذر الاتصال** + 401 | المفتاح ناقص (مقطوع من الآخر) | انسخه تاني بالزر 📋 كامل |
| **تعذر الاتصال** + 404 | ملف `schema.sql` ما اتشغّلش | ارجع لـ SQL Editor وشغّله |
| نجح بس الصور مش بتظهر | المجلد مش Public | Storage → `lab-files` → Edit → Public |

# سادسًا: تأكيد نهائي (٣٠ ثانية)

بعد ما تضغط «حفظ واختبار الاتصال» وينجح:
1. روح **Table Editor** في Supabase → افتح جدول **`lab_data`**.
2. هتلاقيه اتملى بصفوف: `tests` و `packages` و `branches` و `areas` و `doctors`.
3. ده معناه إن بيانات المعمل اتحفظت في السحاب ✅
4. افتح الموقع من **موبايلك** واعمل حجز تجريبي → هتلاقيه ظهر **فوراً** في لوحة المدير على الكمبيوتر 🎉
